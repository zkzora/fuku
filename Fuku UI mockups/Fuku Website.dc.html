AI agents are about to move money. Nobody knows who's behind them.

No reliable identity for the human behind an agent. No portable reputation. No universal permission framework. Every application rebuilds its own trust system. Fuku is the primitive they build on instead.

Human Identity

Passkey sign‑in with WebAuthn. One verified human, provably behind every agent they own.

What is this AI allowed to do? Allowances, limits and hard blocks, enforced on‑chain, readable by anyone.

Developer SDK

Integrate trust.
Skip the infrastructure.

Five calls cover identity, registration, permissions and scoring. Agent activity indexed by Envio, explained by Kimi/Qwen.

Open developer consoleGet API keys →
const id = await fuku.createIdentity({ passkey })
const agent = await fuku.registerAgent({
owner: id, name: 'Trading Assistant'
})
await fuku.requestPermission(agent, {
allow: ['swap'], limit: 5000, block: ['withdraw']
})
const score = await fuku.getTrustScore(agent) // 96
